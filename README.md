# 🏙 Печатный Город

Cozy-игра для обучения печати для детей 6–12 лет: строй город, печатая слова.
Чистый HTML5 Canvas + ванильный JS, без зависимостей, работает офлайн.

## Играть

Просто открой `index.html` в браузере — или играй по ссылке GitHub Pages
(см. Settings → Pages этого репозитория).

## Что внутри

- **29 уровней** — карта-дерево с развилками: путь через стройку или еду,
  через слова или дороги
- **Печать везде**: адреса клеток («б3 лес»), команды с количеством
  («продать фрукт 3»), предложения с заглавными и точками («Мама мыла раму.»),
  режим «дождь слов»
- **Мета-цикл**: звёзды 1–5 за уровни → магазин декораций и питомцев →
  «Мой город», который застраивается тоже печатью
- **Экран родителей**: тепловая карта ошибочных клавиш, динамика точности,
  экспорт JSON
- Прогресс сохраняется в браузере (localStorage)

## Разработка

| Файл | Назначение |
|------|-----------|
| `index.html`, `game.js` | вся игра (движок, уровни, экраны) |
| `layout.json` | раскладка панели: зона каждого элемента (правится верстаком) |
| `layout.html` | верстак: перетаскивай элементы, «Сохранить» → layout.json |
| `server.py` | локальный сервер: игра + верстак + сохранение раскладки (`python server.py`) |
| `DESIGN.md` | как устроена игра |
| `QA_CHECKLIST.md` | обязательный чек-лист тестирования |
| `ROADMAP.md` | план развития |
| `test/harness.js` | автотесты |

Автотесты: открыть `index.html?test=1` — оверлей с результатами.
Демо-режим: `index.html?demo=1` — игра проходит кампанию сама (наблюдай;
 прогресс не сохраняется), `?demo=N` — с уровня N.
Режим разработчика: `index.html?dev=1` (все уровни открыты),
`index.html?level=N` (сразу уровень N).

Вёрстка панели: у каждого элемента своя зона из `layout.json`; клавиатура —
 всплывающая и занимает освобождённое место (список команд + журнал скрываются).
 Верстак: `python server.py` → [layout.html](http://127.0.0.1:8766/layout.html)
 (drag мышью, правка цифрами, «Сохранить» пишет файл).
